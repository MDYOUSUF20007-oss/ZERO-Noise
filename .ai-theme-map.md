## 3. THEME ENGINE CREATION & APPLICATION LIFECYCLE MAP
### (What Changes When a Theme Engine or New Theme Is Made)

When a developer or AI agent creates a new theme engine or activates an existing one, the theme engine orchestrates changes across **seven distinct token layers** and **eight major component surfaces**.

```
+-----------------------------------------------------------------------------------+
|                        THEME ENGINE ORCHESTRATION PIPELINE                        |
+-----------------------------------------------------------------------------------+
| 1. DOM Root Attributes & Classes (data-theme, data-engine, data-accent, dark/light)|
| 2. Seven CSS Token Layers (Canvas, Glass Optics, Inks, Accents, Borders, Radii)   |
| 3. Dynamic UI Surfaces & Components (Dock, Escape Tickets, Void, Dial, Cards)     |
| 4. Hardware Acceleration & Native Android Bridge (GPU safeguard, Quick Settings)  |
+-----------------------------------------------------------------------------------+
```

### A. The 7 Token Layers Injected by Any Theme Engine

Whenever an engine is mounted in [`src/context/InterfaceStyleContext.tsx`](file:///c:/MY%20THINGS/zero-app/src/context/InterfaceStyleContext.tsx), the following seven token layers are applied directly to `:root` / `html[data-theme="..."]`:

#### 1. Background & Canvas Hierarchy
- `--bg-primary`: Deep background canvas (`#08090C` for Fluent Glass, `#000000` for AMOLED, `#F3EDE8` for Aero).
- `--bg-secondary`: Secondary grouping backing (`#0F1217` / `#EDE6DF`).
- `--bg-surface`: Elevated card surface (translucent `rgba(20, 24, 32, 0.50)` in Fluent Glass).
- `--bg-elevated`: Floating modals and popovers (`rgba(26, 31, 42, 0.55)`).
- `--bg-nav`: Bottom navigation dock background.
- `--app-backdrop-gradient`: Ambient canvas radial gradients.

#### 2. Glassmorphism, Optics & Transparency Tokens
- `--glass-opacity`: Glass density slider multiplier (`0.05` to `1.0`).
- `--glass-surface-bg`: Reactive card glass fill (`rgba(20, 24, 32, var(--glass-opacity))`).
- `--glass-specular-opacity`: Top bevel rim optical reflection intensity (`0.12` to `0.80`).
- `--surface-blur`: CSS backdrop-filter blur function (`blur(18px) saturate(140%)`).
- `--glass-inset-bg`: Sunken pill and search bar fills.
- `--glass-dock-bg`: Liquid dock backdrop blur layer.
- `--glass-dial-bg`: Lock dial circular track backdrop.

#### 3. Typography & Ink Tokens
- `--text-primary` / `--zero-ink-primary`: High-contrast headline typography (`#F8FAFC` on dark, `#353B5B` on Aero).
- `--text-secondary` / `--zero-ink-muted`: Subtitles and labels (`#94A3B8`).
- `--text-muted`: Micro telemetry, metadata, and timestamps (`#64748B`).
- `--text-on-accent`: Contrasting text sitting atop solid accent buttons (`#FFFFFF` or `#0F172A`).

#### 4. Accent Spectrum & Luminescence
- `--accent-primary` / `--zero-accent`: Active theme brand color (`#F43F5E` Rose Coral, `#10B981` Neon Emerald, etc.).
- `--accent-secondary`: Secondary harmonious accent tint (`#FB7185`, `#34D399`, etc.).
- `--accent-soft`: 12-16% translucent accent wash for pills and active badges.
- `--accent-glow` / `--liquid-accent-glow`: Outer box-shadow luminescence for active controls.
- `--accent-hex` & `--accent-rgb`: Hex and raw comma-separated RGB channels for alpha blending.
- `--zero-dial-stroke`: Circular session countdown timer stroke color.

#### 5. Specular & Hairline Border Architecture
- `--border-subtle`: 1px translucent perimeter line (`rgba(255, 255, 255, 0.09)`).
- `--border-strong`: Active button and card borders (`rgba(255, 255, 255, 0.18)`).
- `--border-specular`: Top specular light catching rim (`rgba(255, 255, 255, 0.28)`).

#### 6. Status & Telemetry Indicators
- `--status-success`: Active session completions, positive focus streaks (`#10B981`).
- `--status-warning`: Snooze alerts, battery warnings, tamper cautions.
- `--status-danger`: Blocked distraction attempts, emergency exits.

#### 7. Geometric Radii & Metric Scales
- `--radius-card`: Outer card curvature (`20px`).
- `--radius-pill`: Rounded pill tags (`9999px`).
- `--radius-btn`: Operational action buttons (`14px`).

## 4. Checklist: How to Create a New Theme Engine in 6 Steps

Follow these exact steps whenever adding a new theme engine:

1. **Create Engine File**: Create `src/themes/engine-<name>.ts` exporting a `ThemeEngineDefinition` with `id`, `name`, `badge`, `description`, `swatches`, and `css` block.
2. **Register Canonical ID**: Add the new theme id to `CanonicalThemeId` in [`src/themes/types.ts`](file:///c:/MY%20THINGS/zero-app/src/themes/types.ts).
3. **Register in Registry**: Export the engine in [`src/themes/index.ts`](file:///c:/MY%20THINGS/zero-app/src/themes/index.ts), adding it to `THEME_ENGINES`, `AVAILABLE_THEMES`, and `normalizeThemeId()`.
4. **Wire Runtime Context**: Add engine branching in `mountIsolatedThemeEngine()` inside [`src/context/InterfaceStyleContext.tsx`](file:///c:/MY%20THINGS/zero-app/src/context/InterfaceStyleContext.tsx).
5. **Add UI Presentation**: Add the preview swatch card in the Themes sub-tab of [`src/components/SchedulesDonateView.tsx`](file:///c:/MY%20THINGS/zero-app/src/components/SchedulesDonateView.tsx).
6. **Verify Liquid Glass & Tickets**: Ensure `EscapeTicketDockButton` and `EscapeTicketModal` render cleanly under the new engine.
